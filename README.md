## RaceDay Management System

## Overview
RaceDay is a centralized event management platform designed to 
streamline race organization, participant registrations, category tracking, and official race results reporting.

 ## User Roles
* Organiser: Has full administrative rights to create and edit race events, define event categories, manage entry fees, and view registration metrics.
* Participant: Can browse available race events, register for specific categories, view enrolment status, and access final race results.
